# 广州 ⇄ 悉尼 机票监控看板

一家四口（**3 成人 + 1 小孩**）寒假/暑假往返悉尼的机票比价看板。数据来自 Google Flights 公开查询结果，把所有报价折算成**含 20kg 托运行李的真实总价**再排序。

👉 **打开 [`index.html`](index.html) 即可查看**（单文件，数据已内嵌，双击就能开）。

## 口径与假设

- **航段**：CAN（广州）→ SYD（悉尼），往返，允许中转。
- **人数**：3 成人 + 1 儿童，页面上的价格都是**4 人总价**。
- **停留**：10–15 天（小学一年级，只能寒暑假出行）。
- **行李**：每人每程 20kg。廉航按往返 8 段 × ¥360 ≈ ¥2,880 计；传统航司含 23kg 则记 0。**费用为估算，误差约 ±20%**，页面可改。
- **校历假设**：寒假 2027-01-24 → 02-21，暑假 2027-07-10 → 08-31。真实校历不同的话，页面顶部日期框直接改，表格即时重排。
- **覆盖**：2026-12-01 → 2027-08-25 每 4 天一个出发日 × 10/11/12/13/14/15 天，共 **397 组**有效报价。

## 为什么只有廉航

Google 返回的低价列表里 397 组只出现 1 条传统航司报价（新航 ¥42,180 / 4 人），说明**南航直飞、国泰这类含 23kg 的直飞/全服务航班价格高出一大截**，进不了低价区间。含行李可比的前提下，酷航（经新加坡，约 10h）和宿务（经马尼拉，约 11h）仍然最划算。

## 本地实时版（可点按钮重查）

静态页是快照；想随时重查最新价格，在本地跑：

```bash
python3 tools/server.py          # 打开 http://127.0.0.1:8791/
```

页面上点「↻ 刷新价格」会当场重查约 48 组重点日期（假期内全部 + 最便宜的 24 组 + 前 5 名前后一天 + 随机 4 组），降涨价会弹提示。

## 重新抓取全量数据

```bash
python3 tools/scanall.py         # 写 data/fares_all.json
python3 tools/build.py           # 重新生成 index.html
```

抓取方式：手工拼 Google Flights 的 `tfs` protobuf 参数（见 `tools/enc.py`），用 `lxml` 解析返回的 `AF_initDataCallback` 数据块；遇到限流自动换域名重试（`tools/api.py`）。

## 免责

价格为抓取当时的快照，随时波动；行李费为估算。**实际购票请以航司官网/OTA 下单页的最终价格为准。** 本仓库仅作个人比价参考，与任何航司无关联。
